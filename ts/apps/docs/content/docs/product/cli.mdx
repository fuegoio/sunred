`sunred` manages feeds, entries, folders, and API tokens from the terminal. `sunred-tui` is an interactive, full-screen feed browser.

## Install the CLI

Build both binaries from source:

```bash
cd go/cli
make build
```

Pre-built binaries are on the [GitHub releases page](https://github.com/fuegoio/sunred/releases) — download the one for your platform and add it to your `PATH`.

## Point the CLI at your instance

By default the CLI talks to `http://localhost:8080`. If your API lives elsewhere, tell it once:

```bash
./sunred config set base_url https://api.your-instance.com
```

Configuration is stored at `~/.config/sunred/config.json` (or the equivalent on your OS).

## Log in from the CLI

The CLI uses the device flow: it opens a browser to a confirmation page where you approve its access.

```bash
./sunred login
```

The CLI displays a confirmation code and a URL. If a browser can't be opened automatically, take the URL to any device where you're signed in and approve there. Once you approve, the CLI stores the token and you're ready to go.

Use `--no-browser` to skip auto-opening a browser, or `--url` to override the API base URL for this login only:

```bash
./sunred login --no-browser --url https://api.example.com
```

Tokens issued via the device flow expire after 14 days. Run `sunred login` again to refresh.

<details>
<summary>Manual token setup (alternative)</summary>

If you can't use the device flow, create a token via the web UI or the
API and set it manually:

```bash
./sunred config set token pla_your-token-here
```

</details>

## Commands

### Log in

```bash
sunred login                # log in via the browser (device flow)
sunred login --no-browser    # print the URL instead of opening a browser
```

### Manage feeds

```bash
sunred feeds list              # list all subscriptions
sunred feeds add <url>         # subscribe to a feed
sunred feeds delete <id>       # unsubscribe from a feed
```

### Work with entries

```bash
sunred entries list             # list recent entries
sunred entries list --unread    # list unread only
sunred entries list --starred   # list starred only
sunred entries list --feed 1    # filter by feed ID
sunred entries read <id>        # read a single entry
```

Run `sunred entries list --help` to see all available filters.

### Organize with folders

```bash
sunred folders list          # list folders
sunred folders create <title>  # create a folder
sunred folders delete <id>   # delete a folder
```

### Manage API tokens

```bash
sunred tokens list              # list API tokens
sunred tokens create <label>   # create a token (shown once)
sunred tokens delete <id>       # delete a token
```

### Show your profile

```bash
sunred me                       # show current user profile
```

### Check API health

```bash
sunred health                   # check API health
```

## Browse feeds in the TUI

If you want to read rather than script, the TUI is an interactive feed browser. If you're not logged in, it runs the device-flow login automatically before starting:

```bash
./sunred-tui
```

Pass `--login` to force a re-login even if a token is already saved:

```bash
./sunred-tui --login
```

You move through three views: **Feeds** lists your subscriptions, and pressing enter opens one. **Entries** lists the entries in the selected feed; press enter to read. **Entry** shows the full content, and `esc` takes you back.

Navigation is vim-flavored: move the cursor with `j` / `↓` and `k` / `↑`, open the selected item with `enter` / `l`, go back with `h` / `esc`, refresh the feed list with `r`, and quit with `q`.
